# 统一控制台

安装和启动见仓库根 README。控制台默认绑定 `127.0.0.1:8090`，监控详细页为 `127.0.0.1:8080`。

可查看消息统计、日志、群名单、回复规则与 AI 配置，并启停服务。服务按钮通过 `tools/*win_launcher.ps1` 调用根 `tools/stack.py`，使用根目录的 `.venv`。

完整界面包含麦麦相关页面，需安装 MaiBotOneKey/MaiBot 后使用。可通过 `MAIBOT_HOME` 指定一键包目录、`BOT_PYTHON` 指定麦麦解释器。没有对应数据库和插件时，人物记忆、好感度、CG 等页面没有数据。

QQ 和 OneBot 适配器由部署者自行安装、登录和维护。本仓库不包含自动注入工具；界面中接入端专用按钮不是安装入口。先自行提供兼容 OneBot 的 HTTP 和正向 WebSocket 服务。

主动话题、自动怪话与自动跟进默认关闭。RVC、唱歌与图片扩展需要另配工具、模型和自有素材。发布包不含私人素材、聊天记录或浏览器会话。
