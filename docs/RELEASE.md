# v1.0.0 · Windows QQ 机器人源码发布版

本次公开发布提供 qq-monitor 群消息监控/检索/审核、统一控制台、定制 MaiBot 核心及相关插件源码，并附中文用途、安装、模型配置和排障说明。

## 下载与使用

下载此 Release 的 Source code ZIP 并解压，安装 Windows 64 位 Python 3.12，运行 `setup.bat`；填写自己的 OneBot 账号、令牌与群列表后运行 `start.bat`。QQ 和 SnowLuma 需要自行安装并完成接入。

默认只启动监控和控制台。需要 MaiBot 聊天时，按根 README 安装其 requirements、执行 `tools/setup.py --with-bot`，填好机器人与模型配置后使用 `start.bat --with-bot`。

## 发布范围

- 保留现役定制源码、中性配置模板、必要新增模块与插件，未携带生产 Git 历史。
- 排除真实配置、API 密钥、QQ 登录态、浏览器 Cookie、数据库、聊天记录、人物关系、私人素材、运行时和旧备份。
- 可选 AI/主动功能默认关闭，群/管理员列表留空，不自动清理聊天数据。
- 启动器按目录与进程身份管理本副本；外部 QQ/SnowLuma、自启任务和其他应用不由发布版控制。
- 保留 GPL、AGPL 及 A_memorix 特别授权，见 THIRD_PARTY_NOTICES.md。
